# AstroDock

Minecraft **1.20.1**・Forge **47.3.0** 用の高高度飛行 Mod です。オーバーワールドから飛行を続けると、**高度 Y=5,000 で宇宙に突入**します。そこは天井ではありません。さらに上昇したり、宇宙にブロックを置いてステーションや航路の目印を作ったりできます。

## ブロックから艦を作る（0.3.0）

Create や外部の物理 Mod は不要です。最初はコア、スラスター、建材数個の小舟で試してください。以下のレシピはすべて不定形です。

| 部品 | 材料（各1個） | コマンドでの入手例 |
| --- | --- | --- |
| 艦船コア | コンパス・鉄ブロック・レッドストーンダスト | `/give @s astrodock:ship_core` |
| スラスター | 溶鉱炉・ブレイズパウダー・鉄インゴット | `/give @s astrodock:thruster` |
| 艦船レンチ | 鉄インゴット・棒・レッドストーンダスト | `/give @s astrodock:ship_wrench` |

1. 艦内に**艦船コア**を置き、スラスターと船体を組みます。組み立て時の艦首は**南（+Z）**です。直進させたいときはスラスターを左右対称に配置します。
2. メインハンドの**艦船レンチでコアを右クリック**して範囲設定を開始します。通常は「全ブロックを含める」、しゃがんで開始すると「コアだけを含める」です。続けてブロックを2つクリックし、コアを含む直方体の対角を指定します。
3. 黄色が範囲枠、水色が船体候補、灰色が除外です。範囲内のブロックを右クリックするたびに**追加／除外**が切り替わります。空気は取り込まず、コア自身は外せません。やり直すときは空中をしゃがみ右クリックします。
4. レンチで**もう一度コアを右クリック**すると、選んだブロックだけが1隻の艦になり、自動搭乗します。**W** で推進、視線の上下で推力の上下成分を調整し、**A/D** で旋回、**S** で逆噴射します。視線だけを横へ向けても艦首は変わりません。宇宙では推力を切っても慣性が残ります。搭乗中の操縦者は酸欠になりません。
5. 建築可能な高度で減速し、**レンチで右クリック**すると近い90度単位の方角に合わせてブロックに戻せます。復元先にブロックがあれば船体はそのままで着艦を拒否します。降りた自分の艦にはレンチを持たずに右クリックで再搭乗できます。

**対応範囲：** 1隻につき範囲512マス（各辺16以下）、選択256ブロックまで。バニラ／他 Mod の通常の立方体建材を対象とし、チェストや稼働中の機械などのブロックエンティティ、液体・水没ブロック、破壊不能・非フル衝突形状のブロックは組み立て前に除外が必要です。飛行中は船体を1エンティティとして扱い、船内機械の稼働・艦内歩行・複数人搭乗は非対応です。

**物理モデル：** 0.4.0 から3軸の並進とピッチ・ヨー・ロールを扱います。W/S と視線の上下で偏向推力とピッチ制御が働きます。A/D はヨー、**オフハンドに艦船レンチを持つと A/D はロール**です。主機を重心より下に置くと前進時に機首が上がります。着艦時は従来どおり水平・90度単位の方角に合わせます。

建材の硬さを質量の目安とし、立方体の慣性、重心からの距離、質量の偏りを含む逆慣性テンソルとスラスター位置の和を建造時に計算します。飛行中は1艦につき1剛体を積分し、各ブロックは走査しません。姿勢はクォータニオン、回転の状態は世界座標の角運動量で保持し、宇宙との往復・ワールド保存後も引き継ぎます。0.3.0 の艦は旧ヨー角と旋回速度から読み替えます。

衝突は回転後の船体を包むワールド軸沿いの箱で近似します（斜めの狭い通路では見た目より早く接触することがあります）。箱の寸法は回転時のみ更新し、接地・静止した無人艦の支持面は10 tick ごとに確認します。速度上限は並進3ブロック/tick、回転8度/tick です。

性能は `./gradlew runGameTestServer` の `ASTRO_BENCH` 行で比較できます。8／256ブロック、1／32隻について旧ヨー物理と6自由度の積分、同じ地形での衝突問い合わせを別々に計測します。数値はウォームアップ後5回の中央値（各艦群1ステップのナノ秒）で、描画・通信・サーバー全体の時間を含みません。

## カプセルでの最初のフライト

1. 次の並びで**飛行カプセル**をクラフトします。チートが有効なら `/give @s astrodock:flight_capsule` でも入手できます。

   | 鉄インゴット | ガラス | 鉄インゴット |
   | --- | --- | --- |
   | 鉄インゴット | レッドストーンダスト | 鉄インゴット |
   | 空欄 | ブレイズロッド | 空欄 |

2. カプセルを手に持ち、行きたい方向を向いて使用ボタン（通常は右クリック）を長押しすると推進します。離すと推力が止まります。カプセルは一人用の手持ち装置で、メインハンドまたはオフハンドに持っている間は酸欠から保護されます。専用サーバーで遊ぶ場合は、サバイバル飛行が不正飛行と判定されないよう `server.properties` の `allow-flight=true` を設定してください。
3. Y=200 から画面左上に連続高度が出ます。Y=5,000 で X・Z と進行方向を保って宇宙に移ります。宇宙から降下して同じ境界を下回ると地上世界に戻ります。移動後に推力が切れたら、使用ボタンを押し直してください。

## 高度で何が変わるか

| 表示高度 | 環境と飛行 | 描画の準備開始 |
| --- | --- | --- |
| 320〜800 | 雲の上で空が濃い青へ。重力と空気抵抗は通常どおり。 | 200 |
| 800〜2,000 | 群青から藍色へ変化し、薄雲が見える。速く飛ぶほど風切り音とカメラの振動が強まる。 | 700 |
| 2,000〜3,500 | 空が黒ずみ、星が現れる。プレイヤーの重力と空気抵抗が弱まり、推力を切っても慣性が残る。高速降下すると再突入の火花が出る。 | 1,800 |
| 3,500〜5,000 | 星空が鮮明になり、カプセルのエンジン音は低く、風切り音は小さくなる。 | 3,200 |
| 5,000 以上 | 黒い空と星、真空、通常の約 2% の低重力。風切り音と再突入エフェクトはなくなる。 | 直前の帯の星空を再利用 |

生身のエリトラは Y=1,200 から徐々に揚力を失い、Y=1,500 で滑空が解除されます。カプセルなしのサバイバルでは Y=1,500 から酸欠ダメージ（ハート1個）が始まり、間隔は4秒から短くなり Y=2,000 以上では1秒です。

## 宇宙で建築する

宇宙は空のディメンション `astrodock:orbit` です。通常のワールドの建築高度は変更しません。宇宙での **表示高度 = ローカル Y + 5,000**。たとえば F3 で Y=64 の地点は表示高度 Y=5,064 です。建築できるのは表示高度 **5,000〜6,023** で、それより上にも飛行できます。原点付近の足場（バニラのボイド開始台）を建築の起点にできます。チートで離れた場所に最初のブロックを置く例：

```mcfunction
/execute in astrodock:orbit run setblock 100 64 100 minecraft:iron_block
```

宇宙全体や遠くの星をシミュレーションする方式ではありません。星と薄雲は観測者の周囲にだけ描き、描画データは現在の帯と、準備高度に達した次の帯だけ保持します。軌道力学・自動生成のステーション・他 Mod の乗り物ごとのディメンション転送には対応していません。ネザーやエンドに高度の効果はかかりません。

## ビルドと確認

JDK 17 を用意し、リポジトリ直下で `./gradlew clean build`（Windows は `.\gradlew.bat clean build`）を実行します。初回は依存ファイルの取得にインターネット接続が必要です。出力は `build/libs/astrodock-0.4.0.jar` です。Forge を導入したゲームの `mods` に入れてください。マルチプレイではサーバーとクライアントの両方に必要です。

- `build` は描画準備、失速、酸欠、低重力の境界値テストも実行します。プッシュ後は GitHub Actions「Mod のビルド」の成果物 `AstroDock` から JAR を取得できます。
- 開発クライアントは `./gradlew runClient` で起動します。動作確認には新規クリエイティブワールドを推奨します。`/tp @s 100 4995 100` からカプセルで上昇し、宇宙での F3 のディメンション名、連続高度、降下時の帰還を確認できます。
