# AstroDock

Minecraft 1.20.1 / Forge 47.3.0 向けの独立した造船・宇宙航行 Mod です。ブロックで自由な宇宙船・戦艦を造り、艦内を歩いて操縦席や機関室へ移動し、海や空、そして宇宙・火星・惑星ルブラへ航行できます。

**最新配布 JAR：** [astrodock-0.26.0.jar](https://github.com/Python121212/AstroDock/releases/download/v0.26.0/astrodock-0.26.0.jar)

---

## 1. 造船と乗船の基本
1. **外装を組む：** 鉄ブロックや装甲ブロックで密閉された船体を作り、外壁の開口部には **艦外ドア** または **艦外トラップドア** を置きます（通常のドアは艦内の仕切り専用です）。
2. **艦船コアで船化：** 船体の壁面に **艦船コア** を置き、右クリック → **「範囲を確認」** → **「船化する」** を押します。
   - 「範囲を確認」では、**総質量・最大排水量・水密／浸水状態・ノズル推力効率（%）・跳弾率（%）** を確認できます。
   - 自由な範囲で組みたい場合は **艦船レンチ** で対角2点を選択して船化できます（各辺16以下・体積512以下・部品256以下）。
3. **艦内を歩いて移動：** 外から空の手で艦外ドア／ハッチを開けて通ると艦内に入り、歩いて **操縦席** や **機関室** へ移動できます。艦内ではブロックの設置・破壊やチェストの収納も自由です。設備を変更したら艦船コアの **「設備を反映」** を押してください。

## 2. 自作機関・推進・姿勢制御
- **自作機関室：** **機関コア** に **出力部**・**発電部**・**冷却部** を隣接させて組みます。最大出力は `min(4×出力部, 3×発電部)`、冷却は `1 + 2×冷却部` で決まり、使用出力が冷却を上回ると熱が溜まります（熱100で出力半減、40以下で復帰）。
- **自作ノズル：** **ノズル外殻**（中央に黒殻インゴット、上下左右に鉄板）をスラスターの後方に広がるラッパ状に組むと推力効率が上がります（最大 +50%）。逆に真後ろを塞ぐと排気詰まりで遅くなります。
- **重力制御装置（慣性制御）：** 艦内に1個組み込むと、主機作動中にスラスターが重心より低くても後ろへ倒れ込まなくなり、ロール操作を離すと水平へ戻ります。

## 3. 鉄板系・地上鉱石・艦船装甲
- **鉄板系中間素材：**
  - **鉄板：** 鉄インゴットを横に2個並べて作成。スラスター・機関・操縦席・兵装の基本素材です。
  - **層鋼板：** 鉄板＋層鋼片（不定形） → 2×2で **積層装甲ブロック2個**。
  - **重装甲板：** 鉄板＋黒殻インゴット（不定形） → 中央に鉄板・上下左右に重装甲板で **黒殻重装甲ブロック1個**。
- **地上鉱石（新規生成チャンク）：**
  - **層鋼鉱石（Y=0～64）：** 軽い **積層装甲**（質量 3）の素材。
  - **黒殻鉱石（Y=-60～-8）：** 重く強固な **黒殻重装甲**（質量 12）の素材。

## 4. 水上浮力・排水量・船体形状・被弾表現
- **水上浮力と排水量：** 穴のない密閉船体は「外装＋内部空間」の体積に応じた **最大排水量** を持ち、総質量が排水量を下回ると川や海に浮かびます。穴が開いたり重すぎたりすると浸水して沈みます。
- **流線型と跳弾：** 細長い流線型の船体ほど大気中の空気抵抗が減って速く動け、段差・傾斜のある船体ほど敵の砲弾を跳ね返しやすくなります（最大 45% 跳弾）。
- **被弾と穴あき：** ミサイルや魚雷が直撃すると爆発と黒焦げ（煙）が発生し、着弾付近に丸や凹凸の破孔が空いて浸水するようになります。

## 5. 宇宙・太陽・火星・惑星ルブラ
- **宇宙空間（Y=5,000～）：** 高度が上がるにつれて空気が薄くなり、Y=5,000 で宇宙空間へ突入します。
- **メインの太陽：** 宇宙空間では太陽本体・コロナ・プロミネンスが輝き、高軌道では太陽風やプロミネンス周期による活動変化が発生します。
- **火星（`astrodock:mars`）：** 低重力（約 0.38G）により落下速度が抑えられ、ジャンプ力が向上します。
- **惑星ルブラ（`astrodock:rubra`）：** 宇宙から到達できる赤色惑星です。

## 6. 3D 組み方ガイド（Ponder）と操作キー
- **3D 組み方ガイド：** インベントリや造船所タブでアイテムにカーソルを合わせ、**[Shift] を長押し** すると 3D 組み立てガイドが開きます（ドラッグ回転・ホイール拡大縮小・`←/→` でステップ移動）。
- **主なキー設定（設定 → AstroDock で変更可能）：**
  - `G`：主機の起動／停止　｜　`V`：操縦席への着席／離席　｜　`H`：船室への移動／帰還
  - `Z`：主砲（41cm エネルギー砲）　｜　`X`：ミサイル　｜　`C`：魚雷（水中・宇宙両用）
