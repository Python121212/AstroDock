# AstroDock

Minecraft **1.20.1**・Forge **47.3.0** 用の高高度飛行 Mod です。オーバーワールドから飛行を続けると、**高度 Y=5,000 で宇宙に突入**します。そこは天井ではありません。さらに上昇したり、宇宙にブロックを置いてステーションや航路の目印を作ったりできます。

## エンジンと艦内歩行（0.8.0）

組み立てた艦は主機が起動した状態で発進します。旧版の艦にも内蔵主機があり、組み直しは不要です。HUD に「操縦席／艦内歩行」と主機の状態が表示されます。

| 操作（初期設定） | 効果 |
| --- | --- |
| 操縦席で **G** | 主機を停止／再起動。停止すると前後進・上昇・旋回用推力は切れますが、並進と回転の慣性、重力、大気抵抗は残ります。空中での停止はホバリングではありません。 |
| 搭乗中に **V** | 船を降りずに操縦席を離れます。歩行中にもう一度 V を押すと操縦席に戻ります。 |
| 艦内で **W/A/S/D** | 船体に沿って前後左右に歩きます。この間は艦を操縦しません。移動中・旋回中・宇宙との境界移動でも、乗員は艦内の位置に追従します。 |
| 艦内で設備を右クリック | 操縦桿またはコアなら操縦に復帰。**エンジン制御盤**なら艦内から主機を起動／停止します。壁越しや離れた設備は操作できません。 |
| **Shift** | 通常どおり艦外に降ります。飛行中に席を立ちたいだけなら V を使ってください。 |

G/V はゲームのキー設定の「AstroDock」で変更できます。制御盤は造船所タブ、または **鉄インゴット＋レバー＋レッドストーンランプ**の不定形レシピで入手し、任意の船体部品として取り込めます。制御盤がなくても操縦席の G は使えます。

**船室の作り方：** 同じ高さに床を連ね、その上に高さ2ブロックの空間を残してください。壁に制御盤を置き、通路から見える位置に操縦桿を置くと、歩いて機関操作と操縦復帰を試せます。席を離れる際は天井のある床を優先し、船室がなければ開放甲板を使います。歩行は水平な連続床に限定され、床のない場所・壁・低い天井には進めません。階段移動や艦内でのジャンプ、複数人搭乗、飛行中のブロック編集には未対応です。

## 操縦と宇宙の景色（0.7.0）

- 搭乗中に**ジャンプキーを長押し**すると、機首を上げたり W を押したりしなくても上昇します。離すと上昇推力だけが切れます。真空では慣性が残ります。既存の艦でも使用できます。
- **操縦桿**は任意の設置ブロックです。艦橋に置き、船体の選択範囲に含めてください。W/S で推進している間、機首が視線の左右の向きに追従します。A/D の手動入力とロール操作は優先されます。操縦桿のない艦は従来どおりです。
- **選択中のコアを、レンチを持って Shift＋右クリック**すると、1点目・2点目・組み立て直前のどの段階でも範囲設定が解除されます。艦や足場のブロックは変更しません。設定前の Shift＋右クリックは従来どおり「コアだけを含める」で開始します。
- 宇宙で下を向くと、海・大陸・雲・極地のある地球が見えます。地球は帰還方向を示す描画で、地表のチャンクやエンティティは追加しません。帰還は従来どおり宇宙ローカル Y=0 を下回ったときです。地球の海岸線は [Natural Earth](https://www.naturalearthdata.com/) のパブリックドメインデータ（1:110m Land）を使用しています。
- コア、スラスター、飛行カプセル、レンチのテクスチャを刷新しました。操作と見た目の確認は、造船所タブでコア・スラスター・操縦桿・レンチを取り出して小型艦を作り、ジャンプキーで離陸して行えます。

## 宇宙への画面切り替えと造船所タブ（0.6.0）

クリエイティブインベントリの **「AstroDock：造船所」** タブ（青い艦船コアのアイコン）に、艦船コア、スラスター、操縦桿、エンジン制御盤、艦船レンチ、飛行カプセルが並びます。コアは既存の `astrodock:ship_core` と同じブロックです。設置済みのコアやレシピはそのまま使えます。両手を空にしてコアを右クリックすると操作案内が出ます。

地球から Y=5,000、ルブラから Y=512 を越えて宇宙へ向かう有人飛行では、境界の96ブロック手前から上昇中に到着先を先読みします。準備が間に合わなければ元の世界で飛行を続け、到着範囲（5×5チャンク）が揃ってから転送します。先読み用チケットは更新が止まると80 tick で失効し、宇宙全体を常時読み込むことはありません。

飛行中にメニューを開いていなければ、この宇宙への切り替えでは「地形を読み込み中」画面を挟みません。**ディメンションの切り替えやデータ通信自体をなくすものではない**ため、初めての場所や遅い回線では周囲の表示が遅れることがあります。ログイン・死亡時などの通常のロード画面は変更しません。動作を試すには、クリエイティブで `/tp @s 100 4900 100` を実行し、インベントリを閉じて上昇してください。

## 岩石惑星ルブラへ降下する（0.5.0）

1. 宇宙 `astrodock:orbit` で、**ローカル座標 X=1024、Y=384、Z=640**（高度表示なら Y=5,384）の赤茶色の惑星へ向かいます。画面左上に大気圏突入までの距離が出ます。飛行カプセル、クリエイティブ飛行、自作艦で接近できます。
2. 中心から **108ブロック以内** に入ると、進入した方向の経度・緯度に対応する地表ディメンション `astrodock:rubra` の **Y=480** に出ます。惑星中心へ向かう速度は、地表での下向きの速度になります。減速して着陸してください。赤砂岩とテラコッタの丘で採掘・建築・艦の再設置ができます。
3. 地表から **Y=512** まで上昇すると、その地表座標に対応する宇宙側（中心から120ブロック）に戻ります。往復時には速度・視線・艦の姿勢と角運動量を、その地点の天頂が上になるように変換します。

すぐに試す場合は、クリエイティブで `/execute in astrodock:orbit run tp @s 1024 384 800 180 0` を実行し、目の前の惑星へ北（−Z）方向に約52ブロック飛んでください。地球へ戻る従来のルート（宇宙のローカル Y=0 を下回る）は変更していません。

**軽量化：** 宇宙側の球は巨大なブロック構造や常時稼働するエンティティではありません。固定座標と距離の二乗で突入を判定し、実際の転送まで地表チャンクを要求しません。クライアントは距離に応じて72面または512面の静的メッシュを再利用し、極遠方では描画を省きます。宇宙を離れるとメッシュを解放します。地表は通常のチャンク単位で生成・保存し、地形の起伏には水平2次元ノイズを使います。惑星全体の一括生成や常時読み込みは行いません。球面と平らな地表地図を切り替える方式で、連続した球形のブロック地形ではありません。

## ブロックから艦を作る（0.3.0）

Create や外部の物理 Mod は不要です。最初はコア、スラスター、建材数個の小舟で試してください。操縦桿以外の以下のレシピは不定形です。

| 部品 | 材料（各1個） | コマンドでの入手例 |
| --- | --- | --- |
| 艦船コア | コンパス・鉄ブロック・レッドストーンダスト | `/give @s astrodock:ship_core` |
| スラスター | 溶鉱炉・ブレイズパウダー・鉄インゴット | `/give @s astrodock:thruster` |
| 操縦桿 | 上段中央にレバー、下段に鉄インゴット・コンパス・鉄インゴット | `/give @s astrodock:helm` |
| 艦船レンチ | 鉄インゴット・棒・レッドストーンダスト | `/give @s astrodock:ship_wrench` |

1. 艦内に**艦船コア**を置き、スラスターと船体を組みます。組み立て時の艦首は**南（+Z）**です。直進させたいときはスラスターを左右対称に配置します。
2. メインハンドの**艦船レンチでコアを右クリック**して範囲設定を開始します。通常は「全ブロックを含める」、しゃがんで開始すると「コアだけを含める」です。続けてブロックを2つクリックし、コアを含む直方体の対角を指定します。
3. 黄色が範囲枠、水色が船体候補、灰色が除外です。範囲内のブロックを右クリックするたびに**追加／除外**が切り替わります。空気は取り込まず、コア自身は外せません。やり直すときは空中をしゃがみ右クリックします。
4. レンチで**もう一度コアを右クリック**すると、選んだブロックだけが1隻の艦になり、自動搭乗します。**W** で推進、視線の上下で推力の上下成分を調整し、**A/D** で旋回、**S** で逆噴射します。操縦桿なしでは視線だけを横へ向けても艦首は変わりません。宇宙では推力を切っても慣性が残ります。搭乗中の操縦者は酸欠になりません。
5. 建築可能な高度で減速し、**レンチで右クリック**すると近い90度単位の方角に合わせてブロックに戻せます。復元先にブロックがあれば船体はそのままで着艦を拒否します。降りた自分の艦にはレンチを持たずに右クリックで再搭乗できます。

**対応範囲：** 1隻につき範囲512マス（各辺16以下）、選択256ブロックまで。バニラ／他 Mod の通常の立方体建材を対象とし、チェストや稼働中の機械などのブロックエンティティ、液体・水没ブロック、破壊不能・操縦桿以外の非フル衝突形状のブロックは組み立て前に除外が必要です。飛行中は船体を1エンティティとして扱い、自作の船室内を歩けますが、他 Mod の機械の稼働・複数人搭乗は非対応です。

**物理モデル：** 0.4.0 から3軸の並進とピッチ・ヨー・ロールを扱います。W/S と視線の上下で偏向推力とピッチ制御が働きます。A/D はヨー、**オフハンドに艦船レンチを持つと A/D はロール**です。主機を重心より下に置くと前進時に機首が上がります。着艦時は従来どおり水平・90度単位の方角に合わせます。

建材の硬さを質量の目安とし、立方体の慣性、重心からの距離、質量の偏りを含む逆慣性テンソルとスラスター位置の和を建造時に計算します。飛行中は1艦につき1剛体を積分し、各ブロックは走査しません。姿勢はクォータニオン、回転の状態は世界座標の角運動量で保持し、宇宙との往復・ワールド保存後も引き継ぎます。0.3.0 の艦は旧ヨー角と旋回速度から読み替えます。

衝突は回転後の船体を包むワールド軸沿いの箱で近似します（斜めの狭い通路では見た目より早く接触することがあります）。回転と並進の範囲が空のチャンクセクションだけにあり、ワールド境界や衝突対象エンティティもなければ通常の詳細判定を省略します。不明・障害物ありの場合はバニラの移動判定を使います。箱の寸法は回転時のみ更新し、接地・静止した無人艦の支持面は10 tick ごとに確認します。速度上限は並進3ブロック/tick、回転8度/tick です。

性能は `./gradlew runGameTestServer` の `ASTRO_BENCH` 行で比較できます。8／256ブロック、1／32隻について旧ヨー物理と6自由度の積分、同じ地形での衝突問い合わせを別々に計測します。空域ではバニラの問い合わせと空域判定の所要時間も同じ箱で比較します。数値はウォームアップ後5回の中央値（各艦群1ステップのナノ秒）で、描画・通信・サーバー全体の時間を含みません。

## カプセルでの最初のフライト

1. 次の並びで**飛行カプセル**をクラフトします。チートが有効なら `/give @s astrodock:flight_capsule` でも入手できます。

   | 鉄インゴット | ガラス | 鉄インゴット |
   | --- | --- | --- |
   | 鉄インゴット | レッドストーンダスト | 鉄インゴット |
   | 空欄 | ブレイズロッド | 空欄 |

2. カプセルを手に持ち、行きたい方向を向いて使用ボタン（通常は右クリック）を長押しすると推進します。離すと推力が止まります。カプセルは一人用の手持ち装置で、メインハンドまたはオフハンドに持っている間は酸欠から保護されます。専用サーバーで遊ぶ場合は、サバイバル飛行が不正飛行と判定されないよう `server.properties` の `allow-flight=true` を設定してください。
3. Y=200 から画面左上に連続高度が出ます。Y=5,000 で X・Z と進行方向を保って宇宙に移ります。宇宙から降下して同じ境界を下回ると地上世界に戻ります。移動後に推力が切れたら、使用ボタンを押し直してください。

## 高度で何が変わるか

| 表示高度 | 環境と飛行 | 描画の準備開始 |
| --- | --- | --- |
| 320〜800 | 雲の上で空が濃い青へ。重力と空気抵抗は通常どおり。 | 200 |
| 800〜2,000 | 群青から藍色へ変化し、薄雲が見える。速く飛ぶほど風切り音とカメラの振動が強まる。 | 700 |
| 2,000〜3,500 | 空が黒ずみ、星が現れる。プレイヤーの重力と空気抵抗が弱まり、推力を切っても慣性が残る。高速降下すると再突入の火花が出る。 | 1,800 |
| 3,500〜5,000 | 星空が鮮明になり、カプセルのエンジン音は低く、風切り音は小さくなる。 | 3,200 |
| 5,000 以上 | 黒い空と星、真空、通常の約 2% の低重力。風切り音と再突入エフェクトはなくなる。 | 直前の帯の星空を再利用 |

生身のエリトラは Y=1,200 から徐々に揚力を失い、Y=1,500 で滑空が解除されます。カプセルなしのサバイバルでは Y=1,500 から酸欠ダメージ（ハート1個）が始まり、間隔は4秒から短くなり Y=2,000 以上では1秒です。

## 宇宙で建築する

宇宙は空のディメンション `astrodock:orbit` です。通常のワールドの建築高度は変更しません。宇宙での **表示高度 = ローカル Y + 5,000**。たとえば F3 で Y=64 の地点は表示高度 Y=5,064 です。建築できるのは表示高度 **5,000〜6,023** で、それより上にも飛行できます。原点付近の足場（バニラのボイド開始台）を建築の起点にできます。チートで離れた場所に最初のブロックを置く例：

```mcfunction
/execute in astrodock:orbit run setblock 100 64 100 minecraft:iron_block
```

宇宙全体や遠くの星をシミュレーションする方式ではありません。星と薄雲は観測者の周囲にだけ描き、描画データは現在の帯と、準備高度に達した次の帯だけ保持します。軌道力学・自動生成のステーション・他 Mod の乗り物ごとのディメンション転送には対応していません。ネザーやエンドに高度の効果はかかりません。

## ビルドと確認

JDK 17 を用意し、リポジトリ直下で `./gradlew clean build`（Windows は `.\gradlew.bat clean build`）を実行します。初回は依存ファイルの取得にインターネット接続が必要です。出力は `build/libs/astrodock-0.8.0.jar` です。Forge を導入したゲームの `mods` に入れてください。マルチプレイではサーバーとクライアントの両方に必要です。

- `build` は描画準備、失速、酸欠、低重力の境界値テストも実行します。プッシュ後は GitHub Actions「Mod のビルド」の成果物 `AstroDock` から JAR を取得できます。
- 開発クライアントは `./gradlew runClient` で起動します。動作確認には新規クリエイティブワールドを推奨します。`/tp @s 100 4995 100` からカプセルで上昇し、宇宙での F3 のディメンション名、連続高度、降下時の帰還を確認できます。
